## ✨ Features

- 🛒 Browse a collection of flowers with beautiful product cards
- 📦 Add products to cart
- 💳 Simple checkout UI

## 🚀 Getting Started

> Make sure Flutter is installed. [Flutter installation guide](https://docs.flutter.dev/get-started/install)

```bash
git clone https://github.com/your-username/flower_app_ecommerce.git
cd flower_app_ecommerce
flutter pub get
flutter run
```
